# 小说管理系统功能设计

## 一、用户管理
- **注册与基本信息修改**
  - 用户可注册并修改个人基本信息（姓名、性别、出生日期）
  - 支持电子邮箱管理（注册多个邮箱，但仅一个用作用户名）
  - 用户密码安全管理与修改

## 二、个人经历管理
- **教育经历**
  - 记录教育级别、起止年月、学校名称、学位
  - 用户可灵活选择录入全部、部分或不录入个人经历

## 三、小说管理功能
- **搜索与收藏**
  - 支持小说搜索、添加、删除操作
  - 小说分组功能（添加、修改、删除分组）
  - 分组内小说管理（添加、删除小说）

## 四、小说创作功能
- **内容创作**
  - 发表、更改、删除小说
  - 自动记录作者、内容、设定、发表/更改时间

## 五、角色管理
- **角色设定**
  - 创建与管理小说角色
  - 记录角色名称、角色设定内容
  - 角色删除联动（删除角色时相关设定一并删除）

## 六、互动功能
- **评论与回复**
  - 支持对小说进行评论
  - 支持对他人评论进行回复
  - 记录回复信息（发表时间、内容、被回复用户）
